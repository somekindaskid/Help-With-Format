Building the Patrol Goblin

Step 1: Setup & Environment

Start by initializing Pygame and setting up your window and background. We also need a clock to control our frame rate (27 FPS).

import pygame
pygame.init()
win = pygame.display.set_mode((500,480))
pygame.display.set_caption("First Game")
bg = pygame.image.load('Assets/bg.jpg')
clock = pygame.time.Clock()

Step 2: Defining the Enemy Class & Assets

We define the enemy class. Inside, we load the animation frames into lists. These are shared by all instances of the enemy.

class enemy(object):
    walkRight = [pygame.image.load('Assets/R1E.png'), ... , pygame.image.load('Assets/R11E.png')]
    walkLeft = [pygame.image.load('Assets/L1E.png'), ... , pygame.image.load('Assets/L11E.png')]

Step 3: The Constructor (__init__)

This is where we define the goblin's "DNA." We give it a position, dimensions, a path (start/end x-coordinates), and a walkCount for animation.

def __init__(self, x, y, width, height, end):
    self.x = x
    self.y = y
    self.width = width
    self.height = height
    self.path = [x, end]
    self.walkCount = 0
    self.vel = 3

Step 4: Movement Logic

The move() method checks if the goblin has hit its path boundaries. If it hits the end, we flip the vel to negative to make it walk back.

def move(self):
    if self.vel > 0: # Moving Right
        if self.x < self.path[1] + self.vel:
            self.x += self.vel
        else:
            self.vel = self.vel * -1
            self.walkCount = 0
    # ... Same logic for moving left ...

Step 5: The Draw Method

This method draws the goblin. It uses self.walkCount // 3 to slow the animation down so it doesn't look like he's vibrating!

def draw(self, win):
    self.move() # Move before drawing
    if self.walkCount + 1 >= 33:
        self.walkCount = 0
    
    if self.vel > 0: # Draw walking right
        win.blit(self.walkRight[self.walkCount//3], (self.x, self.y))
        self.walkCount += 1
    else: # Draw walking left
        win.blit(self.walkLeft[self.walkCount//3], (self.x, self.y))
        self.walkCount += 1

Step 6: Refactoring the Main Loop

We create a redrawGameWindow() function to keep the loop clean. We then create our goblin object and start the loop.

def redrawGameWindow():
    win.blit(bg, (0,0))
    goblin.draw(win)    
    pygame.display.update()

goblin = enemy(20, 310, 64, 64, 450)
